## What it does

Skills for Fabric is an official Microsoft collection of AI agent skills and MCP servers that let AI coding tools operate over Microsoft Fabric. The skills are reusable instruction sets that GitHub Copilot CLI, VS Code, Claude, and other compatible tools load to understand Fabric workloads, APIs, query patterns, and operational best practices. It ships focused bundles, such as a complete `fabric-skills` suite and a `powerbi-authoring` set, installable through the AI tool's plugin marketplace.

## Why use it

Use it to make your AI coding assistant genuinely fluent in Fabric, so it follows the right APIs, query patterns, and practices instead of guessing, whether you work in the CLI, VS Code, or Claude.

## Getting started

Install a bundle through your AI tool's plugin system. For example, with GitHub Copilot CLI:

```
/plugin install fabric-skills@fabric-collection
```

See the repository and the Skills for Fabric overview on Microsoft Learn for the available bundles and per-tool setup.
